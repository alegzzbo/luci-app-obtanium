# luci-app-obtainium

Веб-интерфейс LuCI для автоматического отслеживания, скачивания и обновления пакетов OpenWrt (`.apk` и `.ipk`) напрямую из релизов GitHub — аналог приложения Obtainium для роутеров на базе OpenWrt.

## Возможности

- **Поддержка современных и классических веток OpenWrt:** автоматическое определение менеджера пакетов (`apk` для актуальных релизов и `opkg` для предыдущих) и архитектуры устройства.
- **Фильтрация сборок под архитектуру:** при выборе файлов релиза автоматически скрываются пакеты для несовместимых архитектур.
- **Гибкий выбор файлов (assets):** возможность выбрать конкретные пакеты из релиза через регулярные выражения / шаблоны имён.
- **Поддержка Pre-release:** опциональное отслеживание тестовых и предварительных сборок для каждого репозитория.
- **Автоматическая проверка и обновление по расписанию:** настраиваемый интервал проверки (в часах) и фоновое автообновление установленных пакетов.
- **Поддержка GitHub API Token:** позволяет обойти лимиты запросов GitHub API (rate limits) и работать с приватными репозиториями.
- **Адаптивный интерфейс:** корректное отображение как на ПК, так и на мобильных устройствах (включая тему Argon).

## Требования

- Роутер с установленной прошивкой **OpenWrt** (поддерживаются ветки на `opkg` и на `apk`).
- Установленные утилиты `curl` / `uclient-fetch` и поддержка HTTPS (`ca-bundle` / `libustream-mbedtls` или `openssl`).

## Установка

1. Скачайте актуальный пакет для вашей версии OpenWrt со страницы [Releases](https://github.com/alegzzbo/luci-app-obtanium/releases):
   - Для актуальных версий OpenWrt (с менеджером пакетов `apk`) — файл `luci-app-obtainium-*.apk`
   - Для предыдущих версий OpenWrt (с менеджером пакетов `opkg`) — файл `luci-app-obtainium-*.ipk`
2. Загрузите файл в директорию `/tmp` на роутере и выполните установку по SSH:

   **Для OpenWrt с `apk`:**
   ```sh
   apk add --allow-untrusted /tmp/luci-app-obtainium-*.apk
   ```

   **Для OpenWrt с `opkg`:**
   ```sh
   opkg update
   opkg install /tmp/luci-app-obtainium-*.ipk
   ```

3. При необходимости очистите кэш LuCI:
   ```sh
   rm -rf /tmp/luci-indexcache /tmp/luci-modulecache/*
   ```

## Использование

После установки раздел **Obtainium** появится в веб-интерфейсе LuCI (в меню **Система** / **Службы**).

1. **Настройки:**
   - При необходимости укажите **GitHub API token** (`ghp_...`).
   - Задайте интервал проверки обновлений в часах (`0` — отключить автоматическую проверку).
   - Включите **Автообновление**, если хотите, чтобы новые версии устанавливались автоматически без ручного подтверждения.
   - Нажмите **Сохранить**.
2. **Добавление репозитория:**
   - Введите репозиторий в формате `owner/repo` или полную ссылку `https://github.com/owner/repo`.
   - Отметьте `pre-release`, если требуется получать предварительные релизы.
   - Нажмите **Выбрать сборки…**, отметьте нужные пакеты из списка и подтвердите выбор нажатием **OK**.
3. **Управление приложениями:**
   - Используйте кнопку **Проверить** для поиска свежих релизов по всем добавленным репозиториям.
   - Нажмите **Установить** напротив нужного пакета или **Обновить все** для массового обновления.

## Сборка из исходников

В репозитории настроен GitHub Actions workflow (`.github/workflows/build.yml`), который автоматически собирает пакеты `.apk` (ветка `stable`) и `.ipk` (ветка `oldstable`) с помощью OpenWrt SDK при создании тега формата `v*` (например, `v1.0.0`).
